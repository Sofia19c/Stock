# 📦 Stock Fácil

Sistema de inventario web desarrollado con Node.js, Express y JavaScript.

## 🚀 Funcionalidades

- Agregar productos
- Actualizar stock (+ / -)
- Eliminar productos
- Buscador de productos
- Dashboard de estadísticas
- Validación de stock
- Persistencia de datos en JSON

## 🛠 Tecnologías usadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- JSON

## 🌐 Proyecto en línea

https://stock-facil.onrender.com/

## 📷 Vista del proyecto

Sistema de control de inventario para pequeños negocios.
